# Git Workflow Auto

When managing workspace git repository:
1. Always run `git status` first to inspect modified, untracked, or staged files.
2. Use `git diff` on specific files to verify surgical line edits.
3. Never perform destructive commands like `git reset --hard` without explicit user intent.
4. Provide clean, meaningful commit messages following standard conventions.
